Snap Full Page (Chrome extension)
Last updated: 23 November 2026 (Asia/Seoul)
Version described: 0.3.0
Contact: kimdoosi@kimdoosi.com

This policy describes how the Snap Full Page browser extension (“the extension”) handles information. It applies to the Chrome Web Store listing and to the installed extension.

Screenshots stay on your device

The extension does not collect, sell, or share your screenshots, page content, browsing history, or annotations. It does not include analytics, advertising, crash reporting, or remote scripts.

When you take a screenshot, pixels are captured in the current tab and processed only on your device. Saved files stay wherever you choose to store them (for example, your Downloads folder or the clipboard).

  • Screenshot images, including crop and annotation data, are stored locally in the browser (IndexedDB) so you can edit them.
  • Local captures are automatically removed after one hour, or when you clear the extension’s site data.
  • Turning Pro off, or removing a license key, does not delete those captures.
  • Optional settings (for example, maximum capture height) are stored in the same local database.

License key — the only user data that leaves the device

Snap Full Page Pro is $9.99 per year and is sold by Polar, the merchant of record. PDF export and auto-blur of emails, phone numbers, and card numbers unlock with a license key. Capture, crop, and annotate stay free. Watermark templates and capturing all tabs at once are not included in this version.

If you enter a license key, the extension sends that key to Polar at https://api.polar.sh so Polar can activate, validate, or deactivate it. Nothing else leaves the device. Screenshots, page addresses, page content, and annotations are not sent to Polar or to us. We do not run our own server for this extension, and the extension contains no access token or other secret.

The same request also includes Polar’s organization id (a fixed value built into the extension), the activation id Polar returns for this device, and an empty label field that Polar’s activate API requires. That label is empty on purpose: it is not your name, a device name, or an account id.

The key is checked again about every 24 hours and when the browser starts. If Polar cannot be reached, Pro remains available for 7 days after the last successful check. If the key is revoked, expired, unknown, or not for this product, Pro turns off immediately and your screenshots stay on the device.

“Upgrade” opens Polar’s checkout in a new browser tab. The extension does not embed Polar’s checkout script. You can manage or cancel the subscription, and request a refund, at polar.sh/doosi/portal. Polar’s receipt email links to that portal as well.

Permissions

The extension requests activeTab and scripting. These are used when you click the toolbar icon or a capture command, so the extension can take and stitch a screenshot of the tab you are looking at. It does not run on every website in the background, and it does not read pages you have not asked it to capture.

It also requests access to https://api.polar.sh/*. That host is used only for the license-key requests described above.

Children

The extension is not directed at children and does not knowingly collect personal information from children.

Changes

If this policy changes, we will update the date above and, when a change is material, the Chrome Web Store listing or an in-extension notice. Version 0.3.0 is the first version that sends a license key to Polar. Earlier versions did not send any data off the device.

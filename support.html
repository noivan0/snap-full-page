What does the free extension do?

It captures a full web page, the visible area, or a selected region, then lets you crop, annotate, copy, and save the image on your device. Screenshots are not uploaded.

Why can’t I capture some pages?

Chrome blocks extensions on browser pages such as chrome://, Settings, the New Tab page, and the Chrome Web Store. Local files need Chrome’s “Allow access to file URLs” setting if you want to capture them.

A very long page was cut off

There is a maximum capture height (default 16,384 CSS pixels, up to 32,766). Open the editor and use “Capture more”, or raise the limit in the extension popup, then continue.

Where are my screenshots stored?

Only on your device. Unsaved captures stay in the browser for one hour, then they are deleted. Use Save PNG, Save JPG, or Copy if you want to keep them.

What is Pro?

Planned Pro features include PDF export and sensitive-information blur. In version 0.2.0 these tools exist in the editor but are locked, and there is no way to buy Pro. Payment is not integrated. This page will be updated before any paid plan is offered.
